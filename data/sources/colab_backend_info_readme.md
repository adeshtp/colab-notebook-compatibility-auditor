## What the repository contains

Quoted from the README: "This repository contains the latest apt-list.txt and
pip-freeze.txt files."

## Data freshness caveat

Quoted from the README, and the most important limitation for this project:

"Be aware that these files do not necessarily reflect the current state of the staging
or production container, but rather the state as of the most recent submitted changes.
There may be a one or two day delay to see the changes in Colab runtimes."

Consequence for this auditor: a package absent from a snapshot's `pip-freeze.txt` is
not proof of absence from a live runtime. This caveat must appear in every generated
report.

## How generation works

Quoted from the header of `pip-freeze.txt` and `os-info.txt`:

```
# Do not modify this file directly; it is generated by extract_colabx_testing_tarballs.sh via
#  $ python3 -m pip freeze
```

and for `os-info.txt`:

```
#  $ (lsb_release -ds;python --version;) > os-info.txt
```

This confirms `pip-freeze.txt` is a `pip freeze` listing and `os-info.txt` holds the
Ubuntu release and Python version. Both are machine-generated, not hand-maintained.
