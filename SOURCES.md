# SOURCES.md — Knowledge Base Provenance

The knowledge base is small and curated. It is **not** a large scraped documentation collection. Each file under `data/sources/` has a matching entry in `data/sources/manifest.json` recording source, title, URL, retrieval date, and runtime context.

## Licensing of vendored data

The `pip-freeze.txt` and `os-info.txt` files under `data/runtimes/` are unmodified output
from `googlecolab/backend-info`, Copyright Google LLC, licensed Apache-2.0. The files
under `data/sources/` are quotations and close paraphrases of public Google Colab
documentation, each carrying its URL and retrieval date. The project code itself is MIT
licensed; see `LICENSE`.

These files are the **sole** source of runtime package versions used by the deterministic rules. They are vendored into `data/runtimes/<snapshot>/` at a pinned commit so analyses are reproducible without network access.

**Known limitation, recorded in the source repository itself:** "these files do not necessarily reflect the current state of the staging or production container, but rather the state as of the most recent submitted CL." Snapshot data can lag a live runtime by one or two days. This is stated in every report's `limitations`.

## Tier 3 — package documentation (not implemented)

There is no third source tier. A question about a specific third-party package's
breaking changes or deprecations has no evidence in this corpus, so it resolves to
`UNKNOWN` rather than being answered from model memory. Adding PyPI or upstream
documentation would mean vendoring and recording provenance for each package, which has
not been done.

## Excluded source types

Not used to build the knowledge base:

- Random blogs
- SEO content pages
- Generic tutorials
- Stack Overflow
- Scraped forum posts

## Retrieved snapshot convention

Curated text files live under `data/sources/<source_id>.md`. Each carries a YAML front-matter block:

```yaml
---
source_id: colab-runtime-version-faq
source: Google Colab
title: Frequently Asked Questions - Past Runtime Versions
url: https://research.google.com/colaboratory/runtime-version-faq.html
retrieved: 2026-10-08
runtime_context: all
content_type: SOURCE_FACT
---
```

`content_type` is either `SOURCE_FACT` (quoted/paraphrased from the source) or `RECOMMENDATION` (our own advice). Retrieval must preserve the distinction. If evidence is missing for a claim, the answer is `UNKNOWN`.
